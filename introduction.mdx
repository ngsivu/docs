Google is a comprehensive technology platform that gives individuals, developers, and organizations access to world-class search capabilities, a full suite of productivity and collaboration tools, and a global cloud infrastructure built for scale. Through a single Google account and a unified set of APIs, you can integrate search into your product, automate workflows with Google Workspace, store and analyze data in the cloud, and deliver reliable services to users around the world.

## What you can do with Google

Google's platform spans four major capability areas. Each area has its own set of services, APIs, and management interfaces — but they all share the same authentication model and developer console, so you only ever need one set of credentials.

## Who this documentation is for

This documentation is written for three audiences:

- **Developers** who want to integrate Google APIs into web, mobile, or backend applications. You'll find API references, authentication guides, code examples, and integration walkthroughs.
- **IT administrators and workspace managers** who need to configure Google Workspace for their organization, manage users and billing, set up SSO, and enforce security policies.
- **Product and business teams** who want to understand what Google's platform offers, how services are priced, and what integrations are possible before handing off to engineering.

If you're new to Google's developer platform, start with the [Quick Start guide](/quickstart) to get your first API call running in minutes. If you need to set up billing, team access, or organizational settings first, head to [Account Setup](/account-setup).

## How the platform fits together

Every Google service runs on shared foundational infrastructure. Your **Google account** (or a **service account** for server-to-server use) authenticates all requests. The **Google Cloud Console** is your central control panel for creating projects, enabling APIs, managing credentials, and monitoring usage and costs. The **Google Workspace Admin Console** handles user provisioning and organizational policies. Both consoles feed into a unified **Billing** interface so you can track spending across all services in one place.

<Note>
  If your organization uses Google Workspace, your administrator may have already provisioned an account for you. Check your work email for an invitation before creating a new personal account.
</Note>
