The Resources API lets you programmatically create and list the files, documents, and data objects stored in your Google workspace. Resources are the core unit of content in the platform — every document, spreadsheet, and file you create is represented as a resource with a consistent structure. All resource endpoints require a valid API token with `resources:read` or `resources:write` scopes. Refer to the [Authentication guide](/api-reference/authentication) for instructions on generating and scoping your tokens.

---

## GET /v1/resources

Retrieve a paginated, filterable list of all resources accessible to the authenticated user. You can narrow results by type, owner, status, or custom tags.

### Query Parameters

<ParamField query="page" type="integer" default="1">
  The page number to retrieve. Starts at `1`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of resources per page. Accepted values: `1`–`100`.
</ParamField>

<ParamField query="sort" type="string" default="created_at">
  Field to sort by. Accepted values: `created_at`, `updated_at`, `name`, `size`.
</ParamField>

<ParamField query="order" type="string" default="desc">
  Sort direction. Accepted values: `asc`, `desc`.
</ParamField>

<ParamField query="filter[type]" type="string">
  Filter by resource type. Accepted values: `document`, `spreadsheet`, `presentation`, `file`.
</ParamField>

<ParamField query="filter[owner_id]" type="string">
  Filter to resources owned by a specific user ID. Example: `usr_01HXYZ123456ABCDEF`.
</ParamField>

<ParamField query="filter[tag]" type="string">
  Filter by a tag slug applied to the resource. Example: `finance`, `q2-report`.
</ParamField>

<ParamField query="filter[status]" type="string">
  Filter by resource status. Accepted values: `active`, `archived`, `trashed`.
</ParamField>

### Request

```bash title="List Resources"
curl --request GET \
  --url 'https://api.google.com/v1/resources?page=1&limit=20&filter[type]=document&sort=updated_at&order=desc' \
  --header 'Authorization: Bearer YOUR_API_TOKEN' \
  --header 'Content-Type: application/json'
```

### Response Fields

<ResponseField name="data" type="array">
  Array of resource objects matching the query.

  <Expandable title="Resource object">
    <ResponseField name="id" type="string">
      Unique identifier for the resource, prefixed with `res_`.
    </ResponseField>
    <ResponseField name="name" type="string">
      Human-readable name of the resource.
    </ResponseField>
    <ResponseField name="type" type="string">
      Resource type: `document`, `spreadsheet`, `presentation`, or `file`.
    </ResponseField>
    <ResponseField name="status" type="string">
      Current status: `active`, `archived`, or `trashed`.
    </ResponseField>
    <ResponseField name="owner_id" type="string">

## POST /v1/resources

Create a new resource in your workspace. You can create a blank resource of a given type, or seed it with initial content by supplying a `content` body.

### Body Parameters

<ParamField body="name" type="string" required>
  The display name for the new resource. Must be between 1 and 255 characters.
</ParamField>

<ParamField body="type" type="string" required>
  The type of resource to create. Accepted values: `document`, `spreadsheet`, `presentation`, `file`.
</ParamField>

<ParamField body="parent_folder_id" type="string">
  ID of the folder to create the resource inside. Omit to place the resource in the root of the authenticated user's Drive.
</ParamField>

<ParamField body="content" type="string">
  Initial content for the resource, encoded as a Base64 string. Optional — if omitted, the resource is created blank.
</ParamField>

<ParamField body="tags" type="array">
  Array of tag slugs to apply to the new resource at creation time.
</ParamField>

<ParamField body="metadata" type="object">
  Optional key-value pairs to attach to the resource for your own reference.
</ParamField>

### Request

```bash title="Create Resource"
curl --request POST \
  --url 'https://api.google.com/v1/resources' \
  --header 'Authorization: Bearer YOUR_API_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Product Roadmap H2 2024",
    "type": "document",
    "parent_folder_id": "fld_01HXYZ999888ZZZYYY",
    "tags": ["product", "roadmap"],
    "metadata": {
      "team": "product",
      "quarter": "H2-2024"
    }
  }'
```

### Response
